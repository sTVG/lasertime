# Space Hopper PWA

This repository contains a simple progressive web app game inspired by 16/24‑bit aesthetics. The player controls an astronaut orbiting planets and taps the screen to boost toward the next planet.

## Features
- Randomly generated planets with increasing difficulty
- Touch controls (press the screen to boost)
- Leaderboard stored in local storage
- Developer info display for orbits and orbit distance
- Basic service worker and manifest for installability

Open `index.html` in a modern mobile browser to play. Scores persist locally and the top 10 are shown below the game.
